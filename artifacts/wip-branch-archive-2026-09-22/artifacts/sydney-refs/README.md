## Geometry note

Utzon’s 1961 spherical solution (official [spherical solution](https://www.sydneyoperahouse.com/our-story/the-spherical-solution)): every sail is a **pointed vault from a ~75 m sphere** (two spherical triangles sharing a ridge), not a latitude/longitude card. Construction photos show precast ribs fanning to an apex, then Höganäs tile skins.
