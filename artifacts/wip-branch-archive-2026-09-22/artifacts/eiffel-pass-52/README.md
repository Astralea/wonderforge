Pass 52 makes the Sauvestre join a **circular arc** (not a half-sine in a
tapering span) and seats **only the north arch** at t=0.32. East, south, and
west arches start at t≥0.40 so their profiles cannot A-frame a due-north
hold. Outer/inner bars are **1.8 m / 1.4 m** so 1.16 m corner posts still
read as legs. P1 square stays after the join; arch cylinders stay Y-to-tangent.
Desktop peak 445k triangles.

This is **not** a Giza-density accept. t=0.32 can read as a north portal
rather than a peaked A-frame; the iron is still not Giza lace, and Champ is
still procedural. K3 has not signed off.
