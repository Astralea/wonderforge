Pass 55 replaces the 18 m warehouse-cube piers with **three coursed
battered masonry solids per leg** (plinth / course / cap matching the
~12 m pylon). Haussmann window bands sit on **park-facing and
camera-facing** walls; mansards are capped so they read as roofs. Pass
54's four station creepers, hidden t=0.12 falsework, lattice arch girder,
and 520 m opening remain.

Desktop peak 521k triangles.

This is **not** a Giza-density accept. t=0.12 can read as four lattice
pylons on stepped plinths; t=0.32 can read as a north lattice portal.
Iron is not Giza lace. Champ is still procedural. K3 has not signed off.
