Pass 42 uses **three ~15.7 m lower storeys** so each Seine-facing X is one
tall diamond (~70 px), not five stacked bays that silhouette as a pillar.
Camera-facing bars are slimmer so holes stay open. Champ îlots are larger,
sparser, and more yawed so the housing grid breaks. Desktop peak 397k
triangles.

This is **not** a Giza-density accept. t=0.32 can show four legs under a
dark P1 deck; the big X reads as spindly wire more than puddled-iron
diamonds (0.5 m bars are ~2 px at 520 m). Night can read as a lanterned
needle; Champ is less of a tight grid but still procedural. K3 has not
signed off.

Lesson: do not thin the Seine-facing stroke below ~1 m on these tall bays.
