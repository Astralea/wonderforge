chords with radial webs, and aims the join look at the **arch belly (~40 m)**
so the curve is not foreshortened into grass beams. Pass 49's pier-to-P1
spring, open Seine back walls, packed îlots, five storeys, and ~400 m
dolly remain. Desktop peak 445k triangles.

This is **not** a Giza-density accept. t=0.32 can still read as four piers
plus a rectangular beam grid rather than a Sauvestre arch. Night can read
as a lanterned needle. Champ is still procedural. K3 has not signed off.
