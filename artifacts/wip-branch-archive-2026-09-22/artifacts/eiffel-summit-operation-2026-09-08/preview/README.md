# Summit operation candidate preview

This opt-in preview uses the actual V4 operation rig (`a5a2a96ede7dd1d1f8b37573e85ba6118bee0226a8ad2bc7ea552eee194a6d82`) and exact public-kit payload members. It renders the cargo rope, full winding, bridle and luff line; the fixed m073 drive; supported terrace/c000 context; and the c001 → pole climb → empty-tackle return → c002 mechanism clock.

The preview has deterministic Play/Pause, 1×/2×/4× speed and direct seeking. `qa.json` records 17 seeks on desktop and mobile with zero page/console errors, at most 230,144 rendered triangles, 20 calls and 18 batches. The 56 → 147 → 56 pixel check returns exactly to its initial image in both modes. The full rig and terrace are visible in the inspected mobile-56 and desktop-230 captures.

This remains a candidate. The earlier ground-to-terrace route and second-stock tackle attachment are explicitly omitted, workers are outside this mechanism clock, and the source upper access/fairlead gate must be evaluated through the separate access evidence before production integration.
