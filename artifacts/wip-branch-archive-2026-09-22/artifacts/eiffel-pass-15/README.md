Each **outward storey face** also seats one **3×3 lace panel** at final size
(scale `[1,1,1]`). Inner walls stay without lace so sky can still read
between the legs.

Dawn shows piers and creeper labour. Mid-BUILD shows denser iron on the
four pylons. Night shows four legs into a lanterned needle. This is **not**
a Giza-density accept: the extra grid can alias into jagged noise at
520–780 m (especially portrait), and K3 has not signed off.
